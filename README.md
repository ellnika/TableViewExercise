# Sectioned Table View — Objective-C / UIKit

An iOS learning exercise from 2016 that displays sample food items in breakfast, lunch, and dinner sections.

## Concepts explored

- Implementing table view data-source methods.
- Organizing section data in a dictionary with an ordered list of headers.
- Reusing table view cells and configuring their text and image.

## Project context

Preserved as part of my earlier UIKit learning history with the original application code. This documentation was added later. The app uses static sample data.

## Exploring the source

The table view implementation is in `test1111/ViewController.m`. Open `test1111.xcodeproj` in Xcode to inspect the project. Compatibility with current Xcode and iOS versions has not been verified.
